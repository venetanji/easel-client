# Easel Studio 0.0.7

Fix template creation and video timeline saves on Windows. Version 0.0.6
could fail with `EPERM: operation not permitted, fsync` when creating a video
or Strudel template because its temporary storage files were opened read-only
before flushing them to disk.

- Open temporary template registry and timeline files with write access before
  flushing and committing them.
- Preserve atomic saves and error recovery when a disk write or flush fails.

Install 0.0.7 over your existing installation, then retry creating the template.
Your saved projects remain in the app's existing data folder.
