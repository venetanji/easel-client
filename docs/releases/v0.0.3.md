# Easel Studio 0.0.3

Fixes a packaged-app startup failure that prevented chat from connecting to the Media MCP server with `ERR_MODULE_NOT_FOUND` for `@modelcontextprotocol/sdk`.

- Unpack the Media MCP runtime dependencies beside the server so ES module imports work in installed Windows, macOS, and Linux apps.
- Verify the packaged server can connect, discover its tools, and list models using isolated packaged files before publishing desktop downloads. The macOS startup check runs after signing.

Windows EXE/ZIP, signed and notarized macOS DMG/ZIP, and Linux AppImage/DEB packages are provided by the release build.
