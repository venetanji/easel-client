# Easel Studio 0.0.4

New installations now open a setup wizard to choose an agent, add credentials or sign in, and prepare a chat model before creating a canvas.

- Built-in setup enables the selected chat model and makes it active. Codex setup checks account sign-in and model selection; External MCP setup checks that a controller is connected.
- Skip setup, resume an unfinished setup after restarting, or reopen the wizard from Settings. Existing configured installations keep their workspace on launch.
- Fix model dropdown interaction inside modal dialogs, including mouse focus and option selection.
- Integrate the Easel media guidance from PR #4: prompting, continuity, audio and camera planning, a pinned LoRA catalog, and clear limits for currently exposed media tools. The server/GPU migration remains a documented follow-up.

This release includes the packaged Media MCP dependency fix and startup verification introduced in 0.0.3.
