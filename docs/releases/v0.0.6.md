# Easel Studio 0.0.6

Create music through Suno, follow background media jobs, and build a Strudel
score in a simpler live editor.

- Enable Suno music, speech and sound generation through configured Media models.
  Studio follows accepted tracks, downloads completed audio, and saves it to
  Media with the track's title and an audio icon.
- Follow generation and download progress in the Jobs tab, with cancellation,
  persistent status, and completion notifications. Media and Jobs share a
  consistent tab row and search layout.
- Use the Strudel interpreter with syntax highlighting, Run/Stop, selection
  execution through Ctrl+Enter, and a collapsible reference panel. Examples show
  their code; Add & run adds a layer to the score instead of replacing it, and
  updates ongoing playback on the same clock. Bundled synths and worklet effects
  work offline. Reopening a project stays silent until Run.
- Improve template selection, back navigation, toolbar labels, file-tab edges,
  History spacing, drawer transitions, and the divider between chat and canvas.
  Remove the video editor shortcut from the main toolbar.
- Include the media onboarding, offline canvas, and Strudel work merged in
  PRs #15, #16 and #17. Existing projects retain their authored source; fresh
  Strudel instances use the updated editor and example controls.

Website sample banks are not bundled. WAV loop export remains limited to the
supported native synth patterns; it does not export arbitrary effects or samples.
