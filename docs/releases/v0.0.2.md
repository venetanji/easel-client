# Easel Studio 0.0.2

## Codex and media

- Enable Codex's tool host and connect Easel MCP before starting a turn, including restored conversations.
- Use native Codex image generation alongside configured Easel image and video models. Requests for a named endpoint use its model ID from `list_models`.
- Keep an already loaded Codex thread between turns and return a structured media model list.
- Restore saved live screenshot previews in chat and preview canvas recordings when captured.
- Show when media is already saved and the agent is preparing its follow-up reply.
- Keep accepted media jobs downloading after Stop without automatically restarting the stopped agent turn.

## Workspace

- Use one viewer tab row, with a trailing **+** for new HTML canvases and a status dot beside each document title.
- Open the Files drawer by clicking the selected document tab. Project ZIP download, Undo, and document device settings live in the drawer.
- Replace chat and media action labels with accessible icons and consistent spacing.
- Sort project media and the shared library newest first using media timestamps.

## Canvas tools

- Request compact source listings with `list_canvas_files({includeAssets:false})`.
- Return saved source paths and revisions from `present_canvas` so agents can edit extracted scripts and styles directly.
- Guide agents toward bounded source reads, atomic edit batches, and one reload and capture with validation.

## Downloads

Windows installers and ZIPs, signed and notarized macOS packages, and Linux AppImage and Debian packages are attached by the tag build workflow.
