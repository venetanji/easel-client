# Easel Studio 0.0.9

Use saved images, source audio and reusable video frames to guide generation,
with prompting guidance from the selected model.

- Retrieve model-specific prompting guides from the configured Easel server and
  apply their format and reference guidance to image and video prompts.
- Supply saved source audio for supported video models. The client preserves
  requested audio and image conditioning through validation and cancellation.
- Extract and reuse video frames as saved image references, with timestamps and
  geometry checks before generation.
- Guide H3 video with saved semantic images and ordered temporal frame groups.
  The client validates the selected model's reference counts, frame positions,
  dimensions and image pixel limits before uploading each reference role.
- Improve timeline playback and media preloading so active clips remain available
  under cache pressure.

Model guides, source audio and H3 reference modes depend on the capabilities
advertised by your configured Easel server. Start a fresh agent session after
updating to load the new tool schemas.

## Downloads

- Windows x64: installer (`.exe`) or portable archive (`.zip`).
- macOS Apple silicon: disk image (`.dmg`) or archive (`.zip`), signed with
  Developer ID and notarized by Apple.
- Linux x64: AppImage or Debian package (`.deb`).
