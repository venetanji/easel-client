# Easel Studio 0.0.1

The first desktop release of Easel Studio: a local workspace for creating interactive canvases, images, and videos with an agent.

## Highlights

- Projects with multiple HTML files, shared media references, offline canvas assets, and ZIP export.
- Built-in agent chat with saved history, attachments, templates, reusable skills, and Stop controls.
- External control through authenticated local MCP, plus embedded Codex chat through the installed Codex CLI and ChatGPT sign-in.
- Image generation, editing, and variation; video generation with persistent background jobs, queue estimates, thumbnails, and completion previews.
- Targeted source editing, managed canvas reloads, live screenshots, video capture, and structured runtime diagnostics.
- Bundled Three.js, p5.js, Phaser, Matter.js, and Tone.js kits; user-controlled camera, microphone, and audio testing.

## Downloads

Choose a package from **Assets** below. Filenames include the operating system and CPU architecture.

| Platform | Package |
| --- | --- |
| Windows | `.exe` installer, or `.zip` containing the app |
| macOS | `.dmg`, or `.zip` containing the app |
| Linux | `.AppImage`, or `.deb` for Debian/Ubuntu |

For the Windows ZIP, extract the whole archive and launch **Easel Studio.exe**. On Linux, make the AppImage executable before opening it.

## Getting Started

Add an endpoint and key in **Settings > Credentials**, refresh its models, and choose an agent model in chat. Media generation uses the enabled media models from your endpoints.

For external agent control, select **Settings > Agent > External MCP** and use its connection instructions. For embedded Codex, install the official Codex CLI, select **Codex**, and sign in with ChatGPT. See the [README](https://github.com/venetanji/easel-client#readme) for setup and canvas contracts.

This first release is unsigned and is not notarized. Canvas content runs offline with local assets; audio playback and device access require a user action. API generation requires your own configured service.
